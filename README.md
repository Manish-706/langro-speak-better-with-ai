# Langro — Web-based Language Learning & Speaking-Practice Platform

Langro (Language + Grow) is a web-based language-learning and speaking-practice platform focused on improving speaking ability through real-time conversations and AI-assisted learning.

## Repository Structure

- `frontend/`: Next.js frontend application
- `backend/`: NestJS modular monolith backend application
- `docs/`: Architecture documentation, API specifications, ADRs, and product roadmaps
